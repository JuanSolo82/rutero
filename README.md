# Rutero

## EStructura básica de la app

Se basa básicamente de una aplicación con desarrollo de una navbar lateral fijado donde se cambia el contenido de la misma dependiendo de los botones presionados, ejemplo de estructura:

```
app/
├── home/
├── paginas/
│   ├── info/
│   ├── header/
│   └── instrumentos/
└── error/
```
